# Texto para publicar o assistente

Copie cada campo para o lugar indicado. As instruções e os arquivos estão em [COMO-USAR.md](COMO-USAR.md).

## ChatGPT (loja de GPTs)

**Nome** (aba Configurar)
```
Contador MEI BR
```

**Descrição** (até 300 caracteres)
```
Tira dúvidas de MEI com a regra oficial e o link: DAS, nota fiscal, declaração anual, dívida e perdão de 2027, teto de faturamento, ocupação (CNAE) e como virar ME. Faz um check-up do seu MEI. Gratuito e aberto. Não substitui contador.
```

**Frases iniciais** (Iniciadores de conversa)
```
Meu MEI está em dia? Faz um check-up comigo.
```
```
Tenho DAS atrasado. Vou ser perdoado em 2027?
```
```
Como emito nota fiscal de serviço sendo MEI?
```
```
Minha atividade pode ser MEI? Eu trabalho com...
```

**Categoria:** Produtividade (ou Educação).

**Imagem do perfil:** use a opção "Gerar com DALL·E" e peça:
```
Ícone simples e plano: uma calculadora com um visto de confirmação, cores verde e azul, fundo claro, sem texto.
```

**Publicar:** Criar > "Loja de GPTs". Para aparecer na loja, a OpenAI pede um nome de construtor verificado (Configurações > Perfil de construtor). Se preferir, escolha "Qualquer pessoa com o link" e divulgue o link.
